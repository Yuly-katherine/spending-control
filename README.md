# 💰 Control de Gastos

Aplicación web para llevar un registro de gastos de manera sencilla y organizada.  
Permite visualizar cuánto dinero se está gastando y administrar mejor las finanzas personales.  


---

##  Características

-  Agregar nuevos gastos con descripción y monto.  
-  Eliminar gastos registrados.  
-  Visualizar el total de gastos y el saldo restante.  
-  Estado global gestionado con `useReducer` y `Context API`.  
-  Estilos modernos y responsivos gracias a **Tailwind CSS**.  

---

##  Tecnologías utilizadas

- [React] 
- [Tailwind CSS] 
- [Context API]
- [useReducer] 

---

##  Instalación y ejecución

1. Clonar este repositorio:  

   ```bash
   git clone https://github.com/Yuly-katherine/spending-control
   cd control-gastos
   ```
2. Instalar dependencias:

```bash
   npm install
```
3. Ejecutar en entorno de desarrollo:

```bash
   npm run dev
```
